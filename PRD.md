# QueueApp Product Requirements Document (PRD)

## 1. Product Overview

QueueApp adalah aplikasi pengelolaan antrian yang dikembangkan secara bertahap.

## 2. Problem

Pengelolaan antrian membutuhkan sistem yang terstruktur agar proses antrian dapat dikembangkan dan dikelola secara lebih baik.

## 3. Product Goal

Membangun dasar aplikasi QueueApp yang dapat dikembangkan secara bertahap mulai dari development environment hingga implementasi fitur aplikasi.

## 4. Week 01 Objective

Pada Week 01, tujuan utama adalah melakukan discovery dan menyiapkan development environment.

Target Week 01:

- Repository QueueApp tersedia.
- Development environment siap digunakan.
- MySQL dapat berjalan sebagai database service.
- QueueApp Server dapat berjalan.
- Web dapat berjalan.
- Ketiga service dapat dijalankan bersama menggunakan Docker Compose.
- Endpoint placeholder dapat diverifikasi.

## 5. Scope

### In Scope

- Repository dan struktur awal project.
- Environment configuration.
- Docker Compose.
- MySQL service.
- QueueApp Server placeholder.
- Web placeholder.
- Dokumentasi awal project.

### Out of Scope

- Implementasi fitur aplikasi antrian secara penuh.
- Implementasi autentikasi.
- Implementasi manajemen pengguna.
- Implementasi sistem tiket/antrian.
- Implementasi dashboard aplikasi.

## 6. Success Criteria

Week 01 dianggap berhasil apabila:

1. MySQL, QueueApp Server, dan Web dapat berjalan bersama.
2. QueueApp Server dapat diakses melalui port 3001.
3. Web dapat diakses melalui port 5173.
4. Repository memiliki dokumentasi dan struktur awal yang diperlukan.
